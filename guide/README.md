# 学习与工程手册

本手册依据当前项目源码与本地 SB3 2.9.0 实现整理，更新于 2026-11-05。目标是能解释数据流、独立做实验并判断修改的影响。先理解输入输出和运行顺序，数学只保留支撑实现的部分。

## 按问题查阅

- 第一次实际运行：从 [09 的准备清单](09_experiments.md) 开始。
- obs/action shape 或控制方向不对：查 03，再查 tests/test_env.py。
- reward 上升但机器人原地站立：查 04 和 07。
- 恢复后学习率没有变化：查 01 的恢复分支。
- 想公开仓库：查 [资源归属](../THIRD_PARTY_NOTICES.md) 和 [整理审查报告](../docs/documentation_review_20261105.md)。
