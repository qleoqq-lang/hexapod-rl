# 实验记录模板

复制到本地logs/<run>/experiment.md后填写。未执行项写“未执行”，不要以预期代替结果。

## 问题与唯一变量

- 实验名称/日期/操作者：
- 假设、修改位置及预期可观测变化：
- 未改基线名称与来源：
- 成功与失败判据（运行前登记）：

## 版本、命令与有效配置

- Git commit及未提交diff；无Git时附源码SHA256清单：
- Python/依赖快照、OS、设备/线程、是否CUDA：
- 完整启动命令与工作目录：
- robot/train配置路径、内容副本和contract：
- 有效模型n_steps、batch_size、n_epochs、learning_rate、gamma、gae_lambda、clip_range、网络结构、n_envs：
- 新建/恢复；父checkpoint路径、哈希、初始计数：
- 训练seed、验证seed、最终测试seed集合与用途：
- 请求/实际训练步数、rollout数、耗时、完成回合数：

## 评估协议与证据

- 评估checkpoint及哈希、选取规则、是否确定性：
- 同种子零动作对照、环境时限、噪声与场景版本：
- 每回合位移、速度、时长、失败原因的原始数据位置：
- 姿态/负载/其他指标的定义、单位、汇总方式及缺失项：
- 日志、曲线、视频或人工观察证据：
- 重复训练次数、均值/分散程度；失败样本是否全部保留：

## 结论与局限

- 观察到什么，是否支持假设：
- 与基线相比的收益及代价：
- 无效对照、数值异常、提前中断及原因：
- 不能从本次实验推断的能力：
- 下一次只改哪一个变量、为什么：
